Example Models#

pgmpy has a collection of Bayesian network models from standard repositories. Some models contain only the graph structure. Other models also contain all parameters, so you can query them and draw samples from them. Use the models for benchmarks, demonstrations, and to learn the API.

Tip

When to use this vs. Example Datasets: Example Models contain graph structures, and some also contain parameters. Use them for inference and simulation. Example Datasets contain data tables. Use them to learn structures and parameters from data.

At a Glance#

Unified API

Find models with list_models(...) and load them with load_model(...).

#api
Filtering

Filter the models by type, parameters, and size before you load them.

Model Families

Discrete, continuous, and structure-only models from the bnlearn, bnRep, and DAGitty repositories.

#available-models

API#

The example-model API is the same as the dataset API. One function finds models, and the other loads them:

from pgmpy.example_models import list_models, load_model

names = list_models(is_parameterized=True, is_discrete=True)
model = load_model(names[0])

print(model)
print(len(model.nodes()), len(model.edges()))

The type of the returned object depends on the model family, for example DiscreteBayesianNetwork, LinearGaussianBayesianNetwork, or DAG.

Filtering#

list_models(**filters) returns only the models that match the filters. You can filter on is_parameterized, is_discrete, is_continuous, is_hybrid, n_nodes, and n_edges.

Model Families#

  • Discrete parameterized: Networks with all CPD tables. Use them for inference and simulation.

  • Continuous: Networks with linear Gaussian parameters.

  • Structure-only: Causal graphs without parameters. Use them for identification and causal reasoning.

You can use a loaded model with all other parts of pgmpy, for example inference, simulation, parameter estimation, and plots.

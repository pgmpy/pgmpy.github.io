Example Datasets#

pgmpy has a collection of benchmark datasets for causal discovery and graphical models. Each dataset contains the data table and its metadata, for example the ground-truth graph, expert knowledge, and tags. pgmpy downloads the data when you load a dataset.

Tip

When to use this vs. Example Models: Example Datasets contain data tables. Use them to learn graph structures and parameters. Example Models contain graph structures, and some also contain parameters. Use them for inference, simulation, and benchmarks.

At a Glance#

Unified API

Find datasets with list_datasets(...) and load them with load_dataset(...).

#api
Filtering

Filter the datasets by data type, size, and metadata before you load them.

#filtering
Bundled Metadata

Each dataset contains its ground-truth graph, expert knowledge, and tags together with the data.

#bundled-metadata
Available Datasets

A table of all datasets with their size, data type, and metadata.

#available-datasets

API#

The dataset API has two functions. One function finds datasets, and the other loads them:

from pgmpy.datasets import list_datasets, load_dataset

matches = list_datasets(is_discrete=True, has_ground_truth=True)
dataset = load_dataset(matches[0])

print(dataset.name)
print(dataset.data.shape)
print(dataset.tags)

The loaded object contains the data as a pandas.DataFrame and all the metadata of the dataset.

Filtering#

list_datasets(**filters) returns only the datasets that match the filters. You can filter on:

  • data type: is_discrete, is_continuous, is_mixed.

  • metadata: has_ground_truth, has_expert_knowledge.

  • size: n_variables, n_samples.

  • data origin: is_simulated, is_interventional.

Bundled Metadata#

Each loaded dataset has these attributes:

  • data: The data table as a pandas.DataFrame. Give it directly to estimator.fit(data).

  • ground_truth: The true causal graph, if the dataset has one. Use it with supervised metrics.

  • expert_knowledge: Domain constraints, if the dataset has them. Use them with discovery algorithms.

  • tags: A dictionary with the properties of the dataset.
